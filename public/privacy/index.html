プライバシーポリシー

「Excel → カレンダー」(以下「本サービス」)
制定日: 2026年11月25日

本サービスは、Excelファイルの内容からAIが予定を抽出し、ICSファイルの書き出し、またはGoogleカレンダーへの追加を行うWebサービスです。本ポリシーでは、本サービスが扱う情報とその取り扱いについて説明します。

1. 運営者

運営者: [運営者名・ニックネーム]
連絡先: [連絡先メールアドレス]

2. 取り扱う情報

  • Excelファイルの内容: アップロードしたファイルは、まずお使いのブラウザ内で読み取られます。ファイルそのものは送信されません。
  • 予定抽出のために送信される情報: 予定の判断に必要な行のテキスト(見出しと各行のセルの内容)が、本サービスのサーバー(Cloudflare Workers)を経由して、Cloudflare Workers AI に送信されます。
  • Googleアカウントの情報: 「Googleカレンダーに直接追加」を使った場合に限り、Googleの認証(OAuth 2.0)で、カレンダーの予定を作成・編集する権限(calendar.events)の許可を求めます。
  • ブラウザに保存される情報: 入力した Google OAuth クライアントIDのみを、お使いのブラウザの localStorage に保存します。

3. 利用目的

  • Excelの内容から予定を抽出し、画面に表示するため。
  • ご自身が確認・承認した予定をICSファイルに書き出す、またはGoogleカレンダーに登録するため。

上記以外の目的では利用しません。

4. 情報の保存・共有

  • 本サービスは、アップロードされたExcelの内容、AIによる抽出結果、Googleアカウントの情報を、データベース等に保存しません。
  • Googleの認証で得られるアクセストークンは、お使いのブラウザ内だけで使われ、本サービスのサーバーには送信されません。Googleカレンダーへの登録は、ブラウザからGoogleのAPIへ直接行われます。
  • 広告、アクセス解析、トラッキング用のCookieは使用していません。
  • 法令に基づく場合を除き、取得した情報を第三者に販売・提供しません。

5. 外部サービスの利用

本サービスは次の外部サービスを利用します。各サービスでの情報の取り扱いは、それぞれのポリシーに従います。

  • Cloudflare(Workers、Workers AI): 予定抽出の処理と、サービスの配信に利用します。通信の運用ログが、Cloudflareにより一定期間保持される場合があります。
  • Google(Googleカレンダー API、Google ID サービス): 直接追加を使う場合の認証と予定の登録に利用します。
  • cdnjs(Cloudflare): Excelの読み取りライブラリの配信に利用します。ページの表示時に、お使いのIPアドレス等が配信元に送信されます。

6. Google ユーザーデータの取り扱い

本サービスによる Google API から取得した情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に準拠します。

  • 要求する権限は、予定の作成に必要な範囲(カレンダーの予定の作成・編集)に限っています。
  • 本サービスは、Googleカレンダーの既存の予定を読み取って保存・利用することはありません。
  • Googleユーザーデータを、広告の表示や、AIモデルの学習に使用することはありません。

7. 許可の取り消し・情報の削除

  • Googleアカウントへの許可は、Googleアカウントの権限設定ページからいつでも取り消せます。
  • ブラウザに保存されたクライアントIDは、ブラウザの閲覧データ(サイトデータ)を削除すると消去されます。
  • 本サービスのサーバーにはデータを保存していないため、サーバー上の削除手続きは不要です。

8. 注意事項

  • AIによる抽出結果には誤りが含まれる場合があります。登録前に、画面で内容を必ずご確認ください。
  • 機密性の高い情報や個人情報を含むファイルのアップロードは、ご自身の判断で行ってください。

9. 改定

本ポリシーは、必要に応じて改定することがあります。改定後の内容は、このページに掲載した時点から効力を生じます。
